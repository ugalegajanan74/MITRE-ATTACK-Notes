# Initial Access

## Description

Initial Access is the first stage of an attack where an attacker gains access to a target system or network.

## Common Techniques

- Phishing (T1566)
- External Remote Services (T1133)
- Drive-by Compromise (T1189)
- Supply Chain Compromise (T1195)

## Detection

- Email gateway alerts
- VPN login monitoring
- IDS/IPS alerts
- Firewall logs

## Prevention

- Enable MFA
- Security awareness training
- Email filtering
- Patch public-facing applications
